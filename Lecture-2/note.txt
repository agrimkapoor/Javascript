JS was invented to run inside browsers. But over time people wanted to run it outside browsers too (like Python runs anywhere). That's where Node.js came in. 

The V8 engine is the actual program that reads your JS and runs it. Google built it for Chrome waala browser. It's both an interpreter and a JIT compiler (it interprets first, then compiles). Node.js literally ripped V8 out of Chrome and bundled it into a standalone program you can run on your laptop. That's all Node.js is at its core
